K8s 官方 HPA 文档：比例式副本计算＋tolerance（默认 10%）＋stabilization window（缩容默认 300 秒取窗口最大值），所有自研 autoscaler 的 baseline 对照组。

3核心贡献

阈值式工业标准实现：比例式副本计算 + tolerance（默认 10%）+ scaleUp/scaleDown stabilization（缩容默认 300 秒取窗口最大值）+ behavior 策略。

条目定位：所有自研 autoscaler 的 baseline 对照组；「工业界如何用简单机制防抖」的活教材。

4核心方法与公式

纯反应式阈值控制：按「当前指标均值 / 目标值」比例计算期望副本数；tolerance 死区过滤小幅抖动；stabilization window 让子弹飞一会儿（缩容侧取窗口内 desired 最大值，防决策打架）。

HPA 阈值公式（K8s 官方）

比例式副本计算：

desiredReplicas = ceil[currentReplicas × (currentMetricValue / desiredMetricValue)]

  • currentReplicas 为当前副本数（整数）；currentMetricValue 为各副本指标均值（如 CPU %）；desiredMetricValue 为目标值
  • 小例子：4 副本、当前 80%、目标 50% → ceil(6.4) = 7

纯比例式对噪声无抵抗，故另配 tolerance（默认 10%）+ scaleUp/scaleDown stabilization（缩容默认 300 秒取窗口内 desired 最大值）+ behavior 策略。

5关键数字

  • tolerance 默认 10%；缩容 stabilization 默认 300 秒（取窗口内 desired 最大值）

6与其它条目的关系

  • Monasca 预测式扩缩容 / SLA-Adaptive HPA：两条改造线都以 HPA 阈值体系为改造对象。
  • Autopilot：生产级「ML + 启发式 + guardrail」路线与 HPA 纯反应式路线的对照。
  • Sieve：系统性测试挖出过 10 个主流 K8s 控制器的 46 个新 bug——HPA 这类控制器的正确性并非理所当然。
