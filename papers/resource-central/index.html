3核心贡献

首次大规模刻画 Azure VM 负载（「历史行为是未来的好预测器」），建成离线训练 + 在线 serving 的预测中台，直接驱动 VM 调度超分。

条目定位：hyperscaler 把「预测」做成平台能力的标准答案——遥测 → 训练 → serving → 多资源管理器调用。

4核心方法与公式

大规模 VM 负载刻画 → 离线训练预测模型 → 在线 serving；预测服务被多个资源管理器（调度 / 超分）调用，而非每个用方自建模型。

7学什么 / 没覆盖什么

学什么

hyperscaler 把「预测」做成平台能力的标准答案：遥测 → 训练 → serving → 多资源管理器调用，而不是每个团队自建模型。

没覆盖什么生产现实

预测的是 VM 生命周期这类慢变量，非分钟级 nowcasting；超分代价模型比在线 SLO 约束简单。
