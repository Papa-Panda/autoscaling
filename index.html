核心公式（分主题）

来自 KNOWLEDGE_MAP.md Part 1 知识树；符号含义见原文"每个符号第一次出现即定义"约定。

T1 需求预测 / Nowcasting

ŷt+1:t+H = f(y1:t, x1:t+H)预测问题设定：yt 为 t 时刻观测需求（核），x 为协变量，H 为预测跨度（分钟）
Lq(y,ŷ) = q·max(y−ŷ,0) + (1−q)·max(ŷ−y,0)Pinball 分位数损失：欠预测被罚 q/(1−q) 倍，"宁可多给"的数学表达
c* = F−1( Cunder / (Cunder+Cover) )报童模型：概率预测 → 容量决策的桥梁；Cunder 欠配代价 ≫ Cover
H ≥ Lact时效硬约束：预测跨度必须覆盖执行延迟，否则决策永远慢一拍

T2 扩缩容算法

desiredReplicas = ceil[ current × (currentMetric / desiredMetric) ]K8s HPA 阈值公式；配 tolerance 10% + stabilization window 防抖
ŝt+1 = α·xt + (1−α)·ŝt指数平滑（Autopilot ensemble 基本单元）；α 大跟随快但抖、小平滑但滞后
u(t) = Kpe(t) + Ki∫e + Kd·de/dtPID 控制器（Padala 2007）；当执行延迟 L ≫ 控制周期，基于过期信号决策 → 抖振

T3 SLO 感知

P(L > S) ≤ ε尾延迟 SLO：L 为单请求延迟，S 为目标（如 200ms），ε 为允许破损率（如 0.001）
R = max( Q1−δ(F̂), Rfloor )悲观防护：走预测分布上分位数 + 硬下限兜底，宁可过配不赌预测
t99 = 4.605 / (μ − λ)M/M/1 直觉：利用率 ρ→1 时尾延迟发散；超卖必须配 guardrail 的排队论根因

T4 压测与验证

N = X·(R + Z)Little 定律：closed-loop 负载下 N 虚拟用户，系统恶化时负载自动掉 → 藏住过载
保真度 = DKL(FR ‖ FS)合成负载 vs 真实流量的分布距离；越小越好
放行条件：violations(πnew) ≤ violations(πold) 且 cost 更低Shadow / Canary 验证：复制生产流量对比窗口 T 内 SLO 指标
